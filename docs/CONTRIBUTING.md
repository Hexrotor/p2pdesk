# Contributing

Contributions are welcome as GitHub pull requests against `main`.

## Pull Request Checklist

- Branch from `main` and rebase on it if needed; unrelated changes belong in
  separate pull requests.
- Keep commits small and individually correct: each commit should compile and
  pass the tests on its own.
- Add tests for a fixed bug or a new feature.
- Describe what you changed and how you tested it in the pull request.

This project is licensed under the [AGPL-3.0](../LICENCE). Signing off your
commits (`git commit -s`, the
[Developer Certificate of Origin](https://developercertificate.org)) is
appreciated, though it is not enforced.

## Conduct

This project follows the [Code of Conduct](CODE_OF_CONDUCT.md).

## Communication

Open a GitHub issue or discussion. There is no chat server for this fork.
