# Security Policy

## Reporting a Vulnerability

Please report vulnerabilities privately through this repository's GitHub
security advisories ("Security" → "Report a vulnerability"). If that channel is
not available to you, open a minimal public issue asking for a private way to
get in touch first — please do not describe an unfixed vulnerability in public.

This fork is maintained on a best-effort basis: there is no bug bounty and no
response-time guarantee.

[SECURITY-STATEMENT.md](SECURITY-STATEMENT.md) documents the threat model and
which mitigations are actually implemented, including the ones that are
explicitly missing.
